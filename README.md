# 播客英语复习室 · The Listening Room

An English podcast learning page for Chinese learners to review what they have learned from podcasts.

已接回 Figma 更新后的网页，后续以这份本地项目继续维护。

## 用户自带内容的学习流程

可下载 [Life Kit 首期英语学习包](public/life-kit-pack-01.json)：理财、日记写作、医保选择三期分章导入，共 31 个表达、45 个主题词汇、76 道选择/填空题、9 个写作话题。合集复用此前的原创练习，并为每章新增原创英文学习导读；导读不是 NPR 逐字稿，表达和例句也不保证是节目原话。合集不含原节目音频，可打开各章官方节目页，或自行添加有权使用的音频。重复导入会跳过已有章节，不覆盖进度。导出文字资料库备份时会保留学习包原有练习，音频仍需单独备份。

新用户打开网页时可导入自己的音频文件、英文逐字稿（可粘贴或导入 TXT/SRT/VTT）和整理好的表达；也可下载[原创免费示范学习包](public/sample-pack.json)，通过导入窗口里的“学习包 JSON”一次填入逐字稿和表达。音频可稍后补充。手动填写表达时，每条按 `英文表达 | 中文含义 | 含该表达的英文例句 | 例句中文` 填写；最后一栏可留空。导入后可以播放自带音频、边听边读、手动划词翻译或高亮，并用原有的记忆卡、表达小测、词汇填空和造句复习。填空题和小测由所填表达自动生成，发布学习包前仍需人工检查题目质量。学习包格式见 [PACK_FORMAT.md](PACK_FORMAT.md)。

音频与逐字稿保存在当前浏览器的 IndexedDB，高亮和进度保存在此网站地址的浏览器存储中；没有账号、跨设备同步或云端备份。可导出、恢复文字资料库备份（期次、逐字稿、表达、高亮、进度、草稿和句子库）；**音频不包含在备份中**，恢复后需要重新添加原文件。清理浏览器数据可能导致未备份的材料丢失。划词翻译优先显示已导入表达的释义；其他文本依赖支持浏览器内置 Translator API 的环境，首次使用可能下载语言包，暂不保证所有浏览器可用，也不会调用 AI 批改 API。

新用户不显示内置节目目录。旧用户若保留历史期次的选择或进度，仍可看到原有三期；因此此版本尚未完全移除历史示例内容。本站不自动抓取节目，也不提供付费购买或授权验证。若未来提供付费包，应以原创讲解与练习为主，第三方完整音频/逐字稿需要单独确认授权。

## 历史内容与旧版维护方式

此前由维护者将播客、视频链接、文字稿或学习笔记整理成内置期次。此方式已经停止作为新用户的默认流程；以下记录保留用于理解和迁移旧版数据。

每一期是 `src/lessons/` 中的一份独立文件。节目标题、日期、来源和数量随所选期次自动更新。维护结构见 `src/types.ts`，新增内容模板见 `templates/lesson.ts.example`。四类练习都应包含有效内容；没有明确来源的文本不要冒充节目原文。

## AI 批改

本项目是纯前端网页，默认不连接 AI 服务，不包含模型 key、批改后台或本机私有配置。普通复习、小测、造句与保存不依赖 AI 服务。

需要批改时，在“话题造句”中点击“连接 AI（可选）”，只填写一个批改 API 地址。填写的是你自己部署的批改服务地址，不是模型厂商的接口，也不是 API key。服务负责保存 key、调用模型并返回反馈；接口约定见 `API.md`。地址只保存在当前浏览器中，不会写入源代码或仓库。清空地址并保存可以关闭连接。

连接后，“AI 检查与润色”会把当前话题、指定表达、原句与扩展句发送到填写的服务，并保存返回的反馈。请求失败时会显示错误，不会冒充批改成功。

## 本地打开

需要 Node.js 22.12 或以上版本和 pnpm。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://127.0.0.1:5178/`。此工作区也可双击 `启动复习室.command`。

```sh
pnpm exec tsc --noEmit
pnpm build
pnpm preview
```

开发模式和预览模式使用同一个端口，请选择其中一种运行。`dist/` 是纯静态网页；AI 批改使用你另外配置的服务。

## 上传到 GitHub

将本项目目录里的源文件上传到你的仓库即可，或使用提供的 `listening-room-github.zip`（解压后上传其中的项目文件）。此专用上传包不含 `node_modules/`、`dist/`、环境配置、key 或本地学习记录。

`.gitignore` 排除了环境配置、依赖、构建结果、日志和常见密钥文件。本项目没有自带批改后台，发布网页后仍可选择自己的 API。上传源代码到 GitHub 与发布一个可访问的网站是两个步骤。

## 部署到 GitHub Pages

仓库已包含 `.github/workflows/deploy.yml`，在 `main` 分支每次推送时构建并发布静态网页。首次部署前，请在 GitHub 仓库打开 **Settings → Pages**，将 **Build and deployment → Source** 设为 **GitHub Actions**。工作流成功后，网页地址为 `https://yzwygxdm.github.io/listening-room/`。部署状态可在仓库的 **Actions** 页面查看。

GitHub Pages 只托管网页，不提供 AI 批改后台。AI 仍默认关闭；需要批改时，使用者自行填写外部服务地址。GitHub Pages 与本地预览属于不同网站地址，浏览器里已有的学习进度和句子不会自动迁移，可使用句子库的导出、导入功能。

## 学习记录

每一期的复习进度与造句草稿分别保存；句子库跨期次共用，记录来源期次和日期。句子与反馈保存在当前设备、当前浏览器、当前网站地址中。

从原来的 Figma 网页或其他地址迁移时，先在那里导出句子库 JSON，再用新版句子库的“导入”按钮导入。已有记录会保留，重复句子不会再次加入。原地址的学习进度不会自动跨网站同步。

## 发布与维护边界

本地修改不会自动回写 Figma Make 或更新其发布网址。当前没有定时采集任务；学习内容由你提供或按你的指示查找公开来源。源代码压缩包不包含 key、本地学习记录或 node_modules。
