# 播客英语复习室 · The Listening Room

An English podcast learning page for Chinese learners to review what they have learned from podcasts.

已接回 Figma 更新后的网页，后续以这份本地项目继续维护。

## 每天怎样更新

你把播客、视频链接、文字稿或学习笔记发到聊天中，或者指定节目与日期范围让助手查找公开来源。助手按原有学习形式整理表达、词汇、例句、小测与造句任务，并加入新的期次。网页顶部可选择旧期次回顾。内容更新保留既有页面样式。

每一期是 `src/lessons/` 中的一份独立文件。节目标题、日期、来源和数量随所选期次自动更新。维护结构见 `src/types.ts`，新增内容模板见 `templates/lesson.ts.example`。四类练习都应包含有效内容；没有明确来源的文本不要冒充节目原文。

## AI 批改

本项目是纯前端网页，默认不连接 AI 服务，不包含模型 key、批改后台或本机私有配置。普通复习、小测、造句与保存不依赖 AI 服务。

需要批改时，在“话题造句”中点击“连接 AI（可选）”，只填写一个批改 API 地址。填写的是你自己部署的批改服务地址，不是模型厂商的接口，也不是 API key。服务负责保存 key、调用模型并返回反馈；接口约定见 `API.md`。地址只保存在当前浏览器中，不会写入源代码或仓库。清空地址并保存可以关闭连接。

连接后，“AI 检查与润色”会把当前话题、指定表达、原句与扩展句发送到填写的服务，并保存返回的反馈。请求失败时会显示错误，不会冒充批改成功。

## 本地打开

需要 Node.js 22.12 或以上版本和 pnpm。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://127.0.0.1:5178/`。此工作区也可双击 `启动复习室.command`。

```sh
pnpm exec tsc --noEmit
pnpm build
pnpm preview
```

开发模式和预览模式使用同一个端口，请选择其中一种运行。`dist/` 是纯静态网页；AI 批改使用你另外配置的服务。

## 上传到 GitHub

将本项目目录里的源文件上传到你的仓库即可，或使用提供的 `listening-room-github.zip`（解压后上传其中的项目文件）。此专用上传包不含 `node_modules/`、`dist/`、环境配置、key 或本地学习记录。

`.gitignore` 排除了环境配置、依赖、构建结果、日志和常见密钥文件。本项目没有自带批改后台，发布网页后仍可选择自己的 API。上传源代码到 GitHub 与发布一个可访问的网站是两个步骤。

## 学习记录

每一期的复习进度与造句草稿分别保存；句子库跨期次共用，记录来源期次和日期。句子与反馈保存在当前设备、当前浏览器、当前网站地址中。

从原来的 Figma 网页或其他地址迁移时，先在那里导出句子库 JSON，再用新版句子库的“导入”按钮导入。已有记录会保留，重复句子不会再次加入。原地址的学习进度不会自动跨网站同步。

## 发布与维护边界

本地修改不会自动回写 Figma Make 或更新其发布网址。当前没有定时采集任务；学习内容由你提供或按你的指示查找公开来源。源代码压缩包不包含 key、本地学习记录或 node_modules。
